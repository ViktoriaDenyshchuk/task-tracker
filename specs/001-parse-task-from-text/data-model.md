# Data Model: Створення задачі з тексту

## Вхідний текст

HTTP запит до парсера; це не збережена сутність.

| Поле | Тип | Правило |
|---|---|---|
| `text` | string | Після перевірки 1–500 символів; не може бути порожнім чи лише пробілами. Інакше HTTP 422 до виклику моделі. |

## Пропозиція парсера

Внутрішня схема, що представляє недовірений результат моделі; не зберігається окремо.

| Поле | Тип | Правило до прийняття |
|---|---|---|
| `title` | string | Після обрізання 1–200 символів. Відсутність, порожнє або довше значення — невалідна/неповна пропозиція. |
| `due_date` | `date \| null` | ISO календарна дата чи `null`; не може бути раніше `get_today()`. Сьогодні дозволено. |
| `priority` | `low \| medium \| high` | Відсутнє -> `medium`; інше значення не проходить валідацію. |
| `tags` | list[string] | Поєднання явних хештегів і валідних запропонованих тегів; після нормалізації без дублікатів, порожніх тегів, максимум 5 (існуюче обмеження `TaskCreate`). |

Неповна структура, відмова, некоректний формат чи невалідна семантика стають контрольованою причиною parser failure. Конкретні причини та retry-поведінка описані у [контракті](contracts/post-tasks-parse.md).

## Збережена задача

Використовується чинний `app.models.TaskCreate` і `Task`; нові поля не додаються.

| Поле | Тип | Правило |
|---|---|---|
| `id` | integer | Призначає `TaskStore`; у `TaskCreate` відсутнє. |
| `title` | string | 1–200 символів. Для fallback це обрізаний вихідний текст довжиною не більше 200 символів. |
| `due_date` | `date \| null` | Необов'язкова дата; fallback приймає лише явний `YYYY-MM-DD`, не раніше сьогодні. |
| `priority` | literal | Одне з `low`, `medium`, `high`; за відсутності вхідної важливості `medium`. |
| `tags` | list[string] | До 5 тегів; trim, lowercase, дедуплікація без урахування регістру. Fallback бере тільки явні `#hashtags`. |

## Відповідь парсингу

Транспортний об'єкт містить `task` (усі поля збереженої задачі) та provenance поля `path` і `parsed`. Для fallback додаються `reason` і `needs_review: true`. Provenance не записується в JSON-представлення задачі.
