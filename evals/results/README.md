# Результати eval

Сюди `evals/run_eval.py --save` записує звіт кожного запуску: дата й час, провайдер, модель, таблиця 8 фраз і висновок за порогом (≥7/8 і 0 невалідних збережених значень).

Кожен звіт — зріз конкретної моделі в конкретний день. Порівнюйте звіти лише з однаковим набором фраз `evals/cases.json`.

Дата `2026-10-12` у cases — фіксований вхід, а дата/час звіту — фактичний запуск. Нові звіти зберігайте у власній робочій копії; prepared result не є live evidence. Вихідний root не містить реалізованого AI-ендпоінта: для нового eval беріть `05_implemented` або власну прийняту реалізацію. У навчальному маршруті eval належить незалежній перевірці перед прийманням зміни.
